# 07 — ما ينتظره المالك من المطور الجديد (قبل تكليفه)

الغرض من هذا المستودع في هذه المرحلة هو **الفهم والمراجعة أولاً**، وليس تفويضاً بتغيير الإنتاج.

## المخرجات المرجوة من مرحلة الاستيعاب
1. خريطة المصدر والاعتماديات مع تفسير كيف تنتقل البيانات من MD إلى dataset إلى GPU trainer إلى checkpoint إلى Android.
2. تقرير قابل للتحقق بكل ما هو Implemented / Tested / Partial / Planned، مع روابط الملفات والاختبارات.
3. تقييم فني لبنية الـtiny scratch Transformer: tokenizer، سياق، ذاكرة GPU، حدود جودة المحادثة.
4. فحص train/holdout provenance والأخطاء المحتملة في التقييم والـcheckpoint/resume.
5. مقترح تصميم Model Registry/Selector بدون تفعيل النسخ التجريبية تلقائياً.
6. خطة لجعل نسخة المشروع قابلة للاستعادة من GitHub + backup مستقل للأوزان والبيانات.
7. تقدير كلفة أي خطة تدريب جديدة قبل طلب تنفيذها.

## لا تفعل قبل طلب صريح
- لا تشغل أو تستأجر GPU؛ المالك طلب إيقافها.
- لا توقف CPU/Studio أو تعدّل المنافذ أو مفاتيح الأجهزة.
- لا تعيد كتابة `training/latest.pt` أو تبدّل live checkpoint.
- لا تبدأ استيراد بيانات عامة أو المستخدمين للتدريب.
- لا تنشر المستودع عاماً أو تشارك الأسرار/الوصول.

بعد تقرير الفهم، سيحدد المالك نطاق العمل الذي تريد تنفيذه.
