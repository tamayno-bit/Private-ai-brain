# Brain Control Android — Markdown upload contract (server v0.1)
Date: 2026-11-22.

## Scope implemented on RunPod CPU Pod
Private AI Brain's owner sidecar (loopback 8877) and Android gateway (6080) now expose three allowlisted endpoints:
- `POST /v1/brain/md-plans` — `Content-Type: application/json`, bearer-device authorization, body `{"filename":"plan.md","content":"# Markdown..."}`. HTTP 201 for new upload, 200 for same-content duplicate. Response: `{"document":{"id":"<sha256>","filename":"plan.md","sha256":"...","bytes":...,"created_at":...,"status":"pending_owner_review","headings":[...],"training_enabled":false,"instructions_active":false,"dataset_imported":false},"already_exists":false}`.
- `GET /v1/brain/md-plans` — returns `{"documents":[...]}`, latest first.
- `GET /v1/brain/md-plans/{64-char lowercase hex sha256}` — returns `{"document":{...},"content":"..."}`; integrity check on read.

Authentication: `Authorization: Bearer <existing device API token>` (the same token already used by Brain Control). Use the existing RunPod HTTPS gateway URL `https://qtf9o6c5bqozsx-6080.proxy.runpod.net`. Do not embed secrets in APK or log their values. The owner API token stays local on the CPU Pod.

## Limits and safety
- Accepts plain UTF-8 Markdown **text** in a JSON object; not multipart binary, file paths or URLs.
- Filename must be a safe basename ending in `.md`, 1-120 characters before suffix; file content must be nonempty, max 128 KiB UTF-8 / 6,000 lines, and not contain NUL, ESC or CR. JSON request max 200,000 bytes.
- Each accepted document is immutable and SHA-256-addressed, retained on the persistent network volume under `/workspace/private-ai-brain-state/md_plans`, with restrictive permissions. Reuploading same bytes is idempotent.
- Uploaded documents are **untrusted information**; no shell, no dynamic file path traversal, no automatic prompting, no training, no dataset ingestion and no automatic approval.
- No public document listing exists without the existing device bearer token; gateway rate limiting remains active.
- Owner must explicitly review and approve future transformations (instructions vs knowledge vs dataset) through future APIs; approval endpoint intentionally does not exist yet.

## Android client change required
The installed Brain Control APK currently offers **local-only** `.md` selection and preview. Its source was not available in accessible RunPod workspace or the connected GitHub repos; therefore this step did **not** modify or rebuild Android UI.
In the existing `MD` tab:
1. Let user select a document through Android Storage Access Framework and preserve the existing local preview.
2. Show the selected filename, byte length, and content summary; require a separate explicit confirmation "رفع للسيرفر".
3. Read as UTF-8 text, apply client-side 128 KiB limit, send the JSON body to `/v1/brain/md-plans` with the existing configured HTTPS base URL + bearer device token. Never send device-local paths or file URI.
4. Handle 201/200 with server-reported document id and `pending_owner_review` status; handle 400/401/413/429 and network failures distinctly without claiming upload succeeded.
5. Add list and preview via GET endpoints; separate upload from approval. Never treat a Markdown document's contents as tool commands or automatic system instructions.
6. Do not auto-retry POST unattended or upload private data without direct user confirmation.
